# Yachiraq

**Crop rotations that protect soil and water, field by field, for smallholder farmers in Chiara (Ayacucho, Peru).** NASA Space Apps Challenge project.

Yachiraq compares 3-year crop rotations for each field using NASA Earth observation data (SRTM/NASADEM, NASA POWER, GPM IMERG, SMAP and MODIS NDVI), soil data from SoilGrids, and the farmer's own answers. It also sends frost and heavy-rain alerts by WhatsApp.
